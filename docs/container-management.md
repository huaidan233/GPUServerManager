# 容器详情、日志与网页终端

在容器列表点击容器名称打开管理面板，不增加常驻侧栏。面板提供概览、日志、终端、连接与存储等标签，可放大；Esc 关闭并恢复焦点，终端内的 Esc 留给 shell 程序。终端内按 Ctrl+Shift+X 将焦点移回操作栏，随后可用 Tab 导航或 Esc 关闭。完整日常步骤见[用户手册](user-guide.md)。

## 用户操作

- 概览区分配置额度与实时采样，Docker 不可达时不显示伪造用量。
- 日志读取最近 100 / 200 / 500 行，最多 64 KiB，支持自动刷新、暂停、跟随末尾与下载当前窗口。日志可能包含应用敏感信息，请谨慎分享。
- 终端需要主动点击连接，使用容器内 `/bin/sh` 和 TTY。托管 SSH 镜像使用 `GSM_SSH_USER`（默认 `researcher`），而不是启动 sshd 的 root；其他镜像必须配置非 root 用户。进入交互 shell 前再次检查有效 UID，绝不回退为 root、不启用 privileged，也不挂载宿主机 Docker socket。
- 关闭面板、切换标签、离开页面或点击断开会释放连接。不要依赖网页连接保活训练任务，需持久运行的任务请使用容器内独立会话或任务调度。断开不是停止容器，也不保证结束已脱离终端的后台进程。
- 连接区显示实际端口映射、容器网络地址、SSH 命令、所有者的独立密码与容器内挂载路径；支持短期证书。停止容器的配置变更可以调整受支持的 SSH 绑定，不提供任意宿主机 Docker CLI / Compose。

## 部署与权限

- 必须配置真实 Server Agent 和 Docker runtime。Noop / InMemory 预览明确禁用终端，不模拟执行成功。
- 镜像必须包含 `/bin/sh` 与 `id` 命令。该功能不依赖容器内 sshd，但仍受容器镜像自身用户与文件权限约束。安装依赖请使用虚拟环境或用户目录，不提供 sudo / root 升权入口。
- 使用现有同源 HTTP 代理：创建、输入和断开走带 CSRF / Origin 校验的请求，输出按游标轮询，避免额外暴露 WebSocket 端口或 Docker daemon。
- `container.exec` 由当前成员角色与能力检查决定；有效的普通成员、教师和管理员在授权范围内使用，每次请求重新校验当前状态与容器归属。会话同时绑定平台登录凭证和容器，其他登录会话不能接管；Agent 端仍验证共享令牌。
- 创建 / 显式关闭记审计，不记录终端输入或输出。浏览器输出缓冲 2,000 行，Agent 每会话 128 KiB、单次输出 64 KiB；输入单次最多 4,096 字符。
- 每个登录会话在同一容器最多两个终端，单 Agent 进程最多 32 个；10 分钟无输入或存续一小时自动关闭，轮询与调整窗口不会延长空闲时间。
- 终端状态驻留 Agent 内存，Agent 应使用单 worker；横向部署必须对同一 Agent 实例保持路由一致。重启会断开会话，用户重新连接即可。
- 所有交互应通过 HTTPS。不要让普通用户访问 Server Agent 共享令牌或 Docker socket。网页终端会赋予用户上述非 root 身份的完整 shell 权限，启用前应审查镜像、挂载与容器隔离。

## 验收

自动测试覆盖权限、CSRF / Origin、会话绑定、输入输出与游标、容量限制、空闲回收、Docker exec 参数，以及弹窗、日志、连接与关闭竞态。真实部署还需用一个可丢弃的托管容器验证：`pwd`、中文输出、Ctrl+C、交互程序、窗口尺寸变化、断线重连、退出 shell、停止容器与会话超时。若本机没有运行 Docker daemon，这部分不能用预览或单元测试替代。
